# comm4190_F25_Final_project

RenovAI is an AI-powered home renovation assistant designed to help users move from inspiration to execution. The app allows users to upload photos of their space, specify a budget and style goals, and receive personalized renovation plans that include layout suggestions, product recommendations, cost estimates based on regional pricing data, and contractor matching. RenovAI bridges the gap between browsing aesthetic ideas online and actually making renovation decisions by providing clear, actionable guidance and visual previews. The goal of this project is to explore how LLMs, computer vision, and structured cost modeling can support real-world decision making in a domain that is often overwhelming, expensive, and opaque for consumers.
